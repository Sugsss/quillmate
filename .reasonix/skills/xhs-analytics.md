# 小红书数据采集 Skill

当用户说"拉取数据"、"更新数据"、"查看表现"时，使用此 Skill。

## 功能
1. 获取所有已发布的笔记列表
2. 模拟采集互动数据（小红书无公开API，需手动录入或浏览器自动化获取）
3. 将数据回填到系统（浏览量、点赞、评论数、收藏数）
4. 展示数据变化趋势

## 使用方式
调用 API：
- GET /analytics/dashboard — 总览数据
- GET /analytics/posts — 内容排行
- PUT /publishes/{id}/stats — 更新单条数据

## 工作流程
1. 获取所有已发布内容的列表
2. 对于每篇内容，用户可以提供最新的互动数据
3. 系统自动计算互动率并排名
4. 用户可查看哪些内容表现最好，指导后续选题

## 手动录入示例
```
PUT /publishes/{id}/stats
{
  "views": 2300,
  "likes": 187,
  "comments_count": 23,
  "collects": 95
}
```
