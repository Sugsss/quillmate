# 小红书内容发布辅助 Skill

当用户说"发布内容"或"导出文案"时，使用此 Skill。

## 功能
1. 从系统中获取最新的待发布内容
2. 导出为适合复制到小红书的格式（标题 + 正文 + 话题标签）
3. 创建发布记录（含发布链接）
4. 提醒用户发布后手动录入链接以便后续追踪

## 使用方式
调用 API：
- GET /contents/export/{content_id} — 导出文案
- POST /publishes/create — 创建发布记录

## 工作流程
1. 列出所有已生成但未发布的内容
2. 用户选择要发布的内容
3. 生成可复制文案，用户复制后到小红书发布
4. 用户提供发布链接后，系统创建发布记录
5. 后续数据采集 Skill 可自动追踪该内容数据
